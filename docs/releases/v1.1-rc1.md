# IA Supervisor v1.1-rc1 Release Candidate Notes

Release candidate tag: `v1.1-rc1`

Date: 2026-06-15

## Summary

`v1.1-rc1` is the first release candidate after MVP1.0. It keeps the product focused on a teacher-led IB Computer
Science IA supervision workflow and adds the hardening needed for a private pilot handoff.

AI review remains advisory only. Teacher judgement remains final.

## Major Changes Since MVP1.0

### Teacher And Student Workflow Polish

- Student dashboard is simplified around next action, criterion progress, and deliverable progress.
- Student feedback pages have more readable Markdown-style formatting and print-friendly layout.
- Teacher review pages separate AI draft notes, teacher feedback drafts, sent feedback, version history, and advanced
  tools more clearly.
- Teacher student detail pages separate teacher-action items from student revision follow-up items.
- Review queue and next-action behavior now avoid focusing on already passed work.

### Deliverables And Final Package

- Subject templates now support criterion documents, video/evidence deliverables, and a final combined IA package.
- Deliverable submissions have version history, teacher review status, and student-facing revision feedback.
- Final submission requires passed criteria and passed class deliverables.
- Teacher report/export tooling shows final package readiness and generates an authenticated ZIP package.

### AI Review Quality And Controls

- AI review prompts are locked to IB Computer Science IA 2027 assessment references.
- AI review output is structured for evidence-grounded, teacher-editable feedback.
- AI review includes quality checks for stale review state, extraction readiness, rubric alignment, and evidence snippets.
- DeepSeek/OpenAI-compatible provider configuration is available through environment variables.
- The project default DeepSeek model is `deepseek-v4-flash`, with `.env` still controlling deployed model selection.
- Teacher AI review has basic per-teacher and per-submission-slot in-memory rate limits.

### Admin And Assessment Reference

- Admin pages cover subject templates, assessment reference files, and system status.
- Admin system status shows seed readiness, assessment reference readiness, masked AI configuration, official fixture
  status, AI review counts, and feedback snapshot counts.
- Subject seeding can initialize assessment templates without creating demo users.

### Delivery Readiness

- Added `npm run readiness:check`.
- Added `npm run readiness:check -- --production`.
- Added `npm run prisma:deploy`.
- Added `npm run admin:create` for real admin bootstrap or password rotation.
- Added `docs/Deployment_Runbook.md` with first deployment, verification, rollback, and production limitation guidance.
- Added `SEED_DEMO_USERS=false npx prisma db seed` path for non-demo reference seeding.

## Production Notes

Before deploying a pilot:

1. Set production `DATABASE_URL`, `NEXTAUTH_URL`, `NEXTAUTH_SECRET`, and `TEACHER_SIGNUP_CODE`.
2. Set `AI_REVIEW_PROVIDER=deepseek` and valid DeepSeek provider variables.
3. Run `npm run prisma:deploy`.
4. Run `SEED_DEMO_USERS=false npx prisma db seed`.
5. Run `npm run admin:create` with a real admin email and temporary strong password.
6. Run `npm run readiness:check -- --production`.
7. Run `npm run ai-review:check-provider`.
8. Mount `uploads/` on persistent private storage.

## Known Limitations

- PDF-only document submissions.
- Uploaded PDFs must contain extractable text.
- Video deliverables are handled as evidence links or uploaded evidence, not in-browser video analysis.
- No online document editing.
- No email notification, email verification, or password reset workflow.
- Local-volume file storage only; object storage is not implemented yet.
- Rate limiting is in-memory and not distributed.
- No school/organization tenant model.
- No malware scanning for uploads.
- AI review is a teacher support tool, not an examiner or grading authority.

## Release Candidate Decision

`v1.1-rc1` is suitable for private pilot acceptance testing with controlled users and a persistent PostgreSQL database.
It is not yet a multi-school public SaaS release.
